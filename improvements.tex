\subsection*{I01. Numerical nonlinear Breit--Wheeler rate table}
\phantomsection\label{imp:I01}
Nonlinear Breit--Wheeler (NBW) pair creation is the conversion of a
high-energy photon into an electron--positron pair in a strong
electromagnetic field. Official 2D EPOCH uses an approximate
analytical rate in \code{pairprod.table}. The 2D
\href{https://github.com/ZheyuanChen/epoch_dev}{fork} adds a
numerical table for the locally constant field approximation
(LCFA), \code{pairprod_lcfa.table}
(\forkcommit{848d21a4b}), selected through
\code{pair_tables = lcfa} (\forkcommit{fd56a2e08}).
The old method remains available as \code{legacy}.
This is an improvement candidate, not a claim that the old
method is a coding error. It can change simulation results,
so record the chosen table and its hash. The local table
generator is currently not committed to the fork; clean
regeneration should be documented before proposing this
for official EPOCH.

\subsection*{I05. Fuller radiation-reaction model and time step}
\phantomsection\label{imp:I05}
The 2D fork adds optional terms of the full
Landau--Lifshitz radiation-reaction force, another
Gaunt-factor fit, and a midpoint time step for the
radiation-reaction force (\forkcommit{dfa48930a}).
The old options remain the defaults. These additions
are not in the checked official \code{main}; the
audited fork branch has no equivalent 3D version.

\subsection*{I06. Laser profiles and phases from data files}
\phantomsection\label{imp:I06}
Zheyuan Chen's \href{https://github.com/ZheyuanChen/epoch_dev}{fork}
can read a laser's spatial or time-dependent profile from a data
file in 2D and 3D (\forkcommit{438424c31}). The laser block accepts
\code{use_custom_profile} and \code{profile_data_file}; the
file-based phase option uses \code{use_phase_from_file} and
\code{phase_data_file}. The implementation also supports separate
data for more than one laser. This feature is absent from the
checked official \code{main}. A portable example should supply
the data file, its format and grid convention, and a reference
field trace; a multi-rank test should also check file loading.

\subsection*{I07. Spin and photon polarisation}
\phantomsection\label{imp:I07}
The fork's \href{https://github.com/ZheyuanChen/epoch_dev/tree/spin}{\code{spin}}
branch adds particle spin and photon polarisation tracking,
with spin-dependent strong-field QED processes in 2D. Zheyuan
Chen began this work by adapting Holger Schmitz's spin-precession
code (\forkcommit{ea37e1a6d}); subsequent fork work adds
spin-dependent emission and pair production
(\forkcommit{773c614c3}, \forkcommit{2b18ef6b4}).
The checked official \code{main} has no equivalent spin model.
The 3D spin/QED port in the fork should be treated as
experimental until its validation is documented. This entry
describes the feature as a whole; it is not a registry of
bugs found only within that feature.
