\section{How to read this document}
This is a shared list of bugs and small improvements to
\href{https://github.com/epochpic/epoch}{EPOCH}. The official
\code{main} branch is the reference point. Bug entries concern faults
in official EPOCH, including ones fixed only in a fork; defects in
fork-only features are excluded. For bugs, the colour shows
where a fix is available: \FixMain\ in official \code{main},
\FixDevel{4.20-devel}\ in an official development branch,
\FixFork\ in a separate copy of EPOCH, or \NoFix\ if no fix is known.
The yellow flag can name any official development branch. A purple
flag does not mean the fix has reached official EPOCH. Click a purple
flag to open the linked fork. Credits name the authors of the cited
fix or improvement; a shared entry may name more than one author.

For improvements, the colour shows where the improvement is available:
\InMain, \InDevel{4.20-devel}, \InFork, or \NotAvailable.
The branch checked for this edition of the register is
\href{https://github.com/epochpic/epoch/commit/f294c484f76dff0777d5cc0d50b38506a2b049ff}{\texttt{f294c484f}}.
The tables are short; click an ID for the explanation and source links.
These checks compare EPOCH files and commit records. They are not
new EPOCH runs.

\section{Adding an entry}
Add one short row to \code{registry.tex} or
\code{improvements_registry.tex}, then add a matching entry to
\code{items.tex} or \code{improvements.tex}. Use a subsection for a
serious bug and smaller headings for the failure, fix and test.
Record the official branch checked and the date when changing a flag.
The copyable examples are in \code{CONTRIBUTING.md}.
